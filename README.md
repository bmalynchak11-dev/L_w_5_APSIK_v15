# Стартовий проєкт APSIK-LAB05

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`. Для частини А потрібні лише Python і `pytest`; Docker потрібен для частини Б та для необов'язкових перевірок на справжніх інструментах.
2. Визначте свою задачу й набір за номером варіанта: задача = `(номер - 1) // 3 + 1`, набір = `(номер - 1) % 3 + 1`. Реалізуйте функцію у файлі `variants/lab_NN.py` за карткою варіанта.
3. Запускайте відкриті тести своєї задачі й свого набору: `pytest tests/test_lab_NN.py -k S2` (замініть `S2` на свій набір: `S1`, `S2` або `S3`).
4. Змінюйте лише свій файл у `variants/` (і за бажанням додавайте `tests/test_my.py`). Файли `tests/obs.py` і `tests/support.py` не змінюйте.
5. Частина Б: у теці `part_b/` піднімете стек спостережуваності для навчального сервісу `shop` (або власного сервісу), побудуєте дашборд і правила сповіщень. Перевірка файлів: `python part_b/check_part_b.py part_b/stack`; пояснення запишіть у `part_b/ANSWERS.md`.
